# 工程记忆入口

初始布局：`standard`（当前布局以 `.memory.json` 为准）。先读当前状态，按任务定位决策、知识与历史。

选择依据（Agent，2026-10-07）：三个 Skill 可以独立迭代，拥有不同的内容边界和验证方式；全局规则与各 Skill 进度需分别维护。因此采用五页全局状态，Skill 专题按需读取。

每轮必读：[[当前状态/项目概览.md|项目概览]]、[[当前状态/当前约束.md|当前约束]]、[[当前状态/当前待办.md|当前待办]]。维护具体 Skill 时通过知识 MOC 找对应专题。

命名边界：`wiki-memory/` 是待分发的 Skill，`wiki_memory/` 是本仓库的记忆。记忆随 Git 保存；实际分支、提交和工作区状态以当轮 Git 检查为准。
