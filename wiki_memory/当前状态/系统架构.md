# 系统架构

## 架构概览

仓库采用“一项 Skill 一个一级目录”的结构。每个 Skill 的 SKILL.md 是自动发现和执行入口；只有真正需要时才加载该 Skill 的 references/、脚本或其他资源。仓库根目录的 AGENTS.md 负责项目级规则，wiki_memory/ 负责持久工程记忆。

## 模块关系

| 模块 | 职责 | 依赖 | 入口 |
| --- | --- | --- | --- |
| AGENTS.md | 仓库级 Agent 规则和 Git 工作约定 | Codex Agent | 会话启动 |
| video-transcript-polisher | 保真整理 Whisper/ASR 课堂转写 | skill-creator 规范 | video-transcript-polisher/SKILL.md |
| video-transcript-polisher/references | 批处理复核和 approved-output 回填 | 主 Skill 的条件路由 | 对应参考文件 |
| wiki_memory | 当前状态、决策、知识、日志和检查工具 | Python 标准库 | wiki_memory/AGENTS.md |

## 数据流

用户请求 → Skill 自动发现或显式调用 → 读取核心 SKILL.md → 仅按需读取模式参考 → 处理或写出目标 → 运行验证 → 记忆同步 → 审核 diff → commit/push。

## 运行与发布

这是一个 Markdown/Git 仓库，不需要常驻服务或构建产物。Skill 通过其目录被加载；仓库变更通过 Git 提交并推送到 origin。
