# 项目概览

mySkills 是 DewMysimple 的个人 Codex Skills 仓库。每个 Skill 以一个独立的一级目录存在，入口是该目录中的 SKILL.md。

## 当前阶段

仓库当前维护 video-transcript-polisher。该 Skill 采用“精简入口 + 按需参考”，并根据真实使用反馈保持适度主动的 Markdown 结构；段落长度和标题数量只作为判断信号，不再作为输出目标，用户明确格式优先。

## 使用者

- 仓库维护者：DewMysimple
- 使用者：需要加载这些 Skill 的 Codex Agent

## 核心目录

| 路径 | 用途 |
| --- | --- |
| video-transcript-polisher/ | 视频课堂 ASR 转写保真润色 Skill |
| video-transcript-polisher/SKILL.md | Skill 的自动发现入口和核心规则 |
| video-transcript-polisher/references/ | 仅在批处理或 approved-output 回填时加载的详细流程 |
| wiki_memory/ | 本仓库的工程状态、决策、知识与日志 |
