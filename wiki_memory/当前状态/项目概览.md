# 项目概览

## 项目目标与阶段

- `mySkills` 是 DewMysimple 开发、管理和分享个人 Codex Skills 的仓库，当前有三个独立能力包。依据：根目录 `AGENTS.md` 与三个 `SKILL.md`。
- 工程记忆采用 standard，保存本仓库的上下文；可复用的 `wiki-memory` Skill 与仓库记忆分开管理。布局依据见 [[入口.md|入口]]。

## 核心入口

- 开发规则：根目录 `AGENTS.md`；对人说明：中文 `README.md`。
- 课堂转录：`video-transcript-polisher/SKILL.md`。
- PDF 书籍转换：`pdf-book-to-obsidian/SKILL.md`。
- 工程记忆能力包：`wiki-memory/SKILL.md`；本仓库维护协议：[[AGENTS.md|记忆协议]]。
- 维护某个 Skill 时，再读 [[知识/MOC_知识.md|知识 MOC]] 中的对应专题及该 Skill 自身的要求。

## 工作区背景

- 记忆接入过程和当时的 Git 基线见 [[日志/2026-10-07-配置仓库工程记忆.md|配置日志]]。每轮重新检查分支、工作区及交付时的远程状态，不把旧日志中的 revision 当作当前 HEAD。
- PDF Skill 有本轮开始前已存在的未提交改动，接续入口见 [[当前状态/当前待办.md|当前待办]]。
