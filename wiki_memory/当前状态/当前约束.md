# 当前约束

## 结构约束

- 一个 Skill 使用一个独立的一级目录，并至少包含 SKILL.md。
- SKILL.md 只放共享目的、核心约束和路由；模式专属细节放在可按需加载的 references/。
- 只有直接支持 Skill 工作的资源才进入 Skill 目录。

## 质量约束

- 创建或修改 Skill 时遵循 skill-creator 指南。
- 修改后运行 quick_validate.py，并做有意义的人工内容检查。
- 不把本地课堂转写样本、处理稿或临时文件加入仓库。
- Skill 不应总结、翻译或改写用户的原始课堂内容，除非用户明确请求不同任务。

## 操作边界

- 默认不覆盖源文件，不扩大用户指定的文件范围。
- 每次完整对话完成一组连贯仓库修改后，审核 diff、验证、提交并推送。
- 不提交无关、未完成或验证失败的修改；推送失败时保留本地提交并报告。
