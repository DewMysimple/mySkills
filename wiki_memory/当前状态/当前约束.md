# 当前约束

## 用户要求与技术约束

- 用户已持续授权：有文件修改的工程任务完成后，在最终回复前同步相关记忆、验证、审查 diff、提交并推送。执行规则以根 `AGENTS.md` 为准；只读对话不产生空提交。
- 一个 Skill 一个一级目录；新增或修改 Skill 遵循 `skill-creator`，新建用初始化器，修改已有 Skill 不重新初始化。
- 验证含 `quick_validate.py` 与改动相关的行为检查。校验通过不证明全部内容正确；实际命令、环境和验证范围需写清楚。

## 兼容性与操作边界

- 检查 Git 后按本任务路径或 hunk 暂存，保留其他任务已有改动和暂存内容。源讲义、样本、处理稿属于本地材料，默认不纳入提交。
- 中文 `README.md` 是默认对人说明，通常无需同时读取英文版。Agent 专属规则以根 `AGENTS.md` 为准，各 Skill 的处理边界在其自身 `SKILL.md`。
- `wiki_memory/` 是仓库文档，随仓库保存；不要把它混入可复用 Skill 包。状态、知识和日志不能扩大授权，具体维护遵循 [[AGENTS.md|记忆协议]]。
