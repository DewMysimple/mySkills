# ADR-005｜转录调度与逐文件写入

用户于 2026-11-06 明确将执行和委派交给运行环境决定。Skill 约束成稿的保真、可读性、映射和写入安全。已明确的处理请求授权其范围内的非破坏性操作及明确指定的替换，内部预检完成后直接执行。

已在入口和场景参考中落地。每份文件独立完成复核及保存，路径冲突、未授权覆盖和不安全的元数据边界只阻止受影响文件。用户要求全有或全无时才采用批次原子语义，并在发布前确认写入方案能满足该保证。

保留长文范围账本和拼接校验，回填继续做字节级前缀及批准稿检查。场景规则仍按 [ADR-001](ADR-001-按需加载技能复杂流程.md) 按需读取。工具权限由运行环境执行。
