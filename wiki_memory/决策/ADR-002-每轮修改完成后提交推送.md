# 每轮修改完成后提交推送

决策者：用户。用户于 2026-10-07 再次明确本工程每轮完成的修改提交并推送；同步得到的旧工程记忆也已有同一约定，本页将本轮持续授权与执行细节留档。

执行约定写入根 `AGENTS.md`：同步相关记忆，完成适用验证，审查 diff，提交本任务变更，推送当前分支至已有 upstream，并在最终回复报告结果。这是本仓库的持续授权，其他项目仍按其自身指令执行。

只读对话无需空提交。其他任务的既有改动与暂存内容保留，不能借本条自动一并提交。Git 交付失败需报告实际阻塞，不强推、不编造成功。

实现位置：根 `AGENTS.md` 的 Working rules。是否已交付某一轮代码，应检查实际 Git 提交与远程分支；此决策页只记录工作规则。
