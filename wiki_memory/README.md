# mySkills 工程 Agent 记忆

这是 mySkills 的低成本、可审计 Markdown 工程记忆。它把“发生过什么”和“现在应该相信什么”分开：日志保留历史，当前状态、决策和知识页提供快速上下文。

## 目录结构

    wiki_memory/
    ├── AGENTS.md                 # 记忆维护协议
    ├── README.md                 # 记忆系统说明
    ├── 当前状态/                  # 会话优先读取的当前事实
    ├── 决策/                      # 已确认的工程决策
    ├── 知识/                      # 模块、流程、规范、运维知识
    ├── 日志/                      # 单次任务的追加式历史
    ├── 模板/                      # 创建页面时使用的模板
    └── 工具/memory_lint.py       # 检查和重建日志索引

## 读取和维护

1. 先读取 AGENTS.md 和 当前状态/ 的四个核心页面。
2. 按任务读取相关决策和知识页，不默认加载全部日志。
3. 实质任务完成后写入一篇日志，并运行 python wiki_memory/工具/memory_lint.py index。
4. 变更记忆结构或内容后运行 python wiki_memory/工具/memory_lint.py check。
