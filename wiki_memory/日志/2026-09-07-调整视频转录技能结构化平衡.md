# 2026-09-07｜调整视频转录技能结构化平衡

- 时间：2026-09-07（北京时间）
- 类型：maintenance
- 状态：完成
- 目标：解决 video-transcript-polisher 处理连续课程转写时只有段落、没有标题层级的问题。
- 日志索引：[[日志/MOC_工作日志|工作日志 MOC]]

## 触发问题

在 M1-01 至 M1-08 的真实使用中，原稿虽有多个清晰的持续主题和方法阶段，但输出全部没有 `#` 或 `##` 标题。原因是“稀疏 Markdown 结构”被执行得过于保守。

## 决策

- 保留高置信度 ASR 纠错、保真、不总结、不翻译、不扩写等边界。
- 将标题策略调整为平衡模式：对清晰的持续主题、独立示例或方法阶段主动添加少量 `##` 标题。
- `#` 仅用于原文已有或用户明确要求的文档标题；多主题转写通常使用约 2–6 个章节标题。
- 增加保存前标题覆盖检查：存在多个持续主题但没有标题时，必须回看主题地图并补充最小有用标题集。
- 对原文明确列举的设计模式或步骤，允许使用有序/无序列表；仍不制造表格、装饰性格式或源文没有的结论。
