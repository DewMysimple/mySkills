# 迭代工程记忆 3.4.0

## 目标与结果

按用户提供的两份文档完成可点击导航、来源复核、项目工具核对和可比较的接续评测。实施时采用文档建议的 3.4.0，保留 Schema 2 和独立项目工具。经本轮授权，仅本仓库显式切换 Markdown 生成样式。旧配置缺字段时继续生成 Wiki 导航，日志表格保留原样。

## 关键变化

- `impact` 对指定 Git 范围列出文件变更、有效页的复核候选、未映射来源和页面核实基线。整页复核可记 `verified_rev`，局部复核维持原整页核实字段。
- `tool-diff` 比较声明版本、原始字节 SHA-256 和配置字段兼容性。先核对项目与 Skill 的差异，再以补丁同步本仓库工具，保留项目协议定制。
- 评测覆盖八类任务和 A/B/C 三组，以固定 3.2.1 提交提取真实 B 组工具。私有 oracle 与运行输入分离。自动评分核对产物和证据，语义判据由独立裁判处理。
- 明确只读窄查询的读取路径。修改、跨分支和恢复仍读完整必需状态，恢复点记录起点、行动、验收与边界。日常检查频率沿用已有协议。
